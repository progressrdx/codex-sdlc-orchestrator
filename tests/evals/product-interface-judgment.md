# 产品界面判断：行为评测

这是离线能力评测材料，不是运行时新增流程，也不是已经通过的测试报告。普通 unittest 与 Skill 校验只能证明打包/引用等机械性质，不能给下面的产品判断打分。

## 执行方法

对比旧版和候选版的产品判断参考，使用相同输入、模型配置与可用工具，每例使用干净上下文。模型只读取对应版本 `sdlc-product/references/interface-judgment.md`（旧版不存在时使用旧 `visual-direction.md`）和所需视觉参考；不提供后面的评审要点或本次已知结论。不调用外部设计 Skill，不生成页面，不创建正式工作项或伪造产品批准。此轮验证的是内置产品判断，不是完整多角色流程。

统一追加任务：“给出简短产品判断：主要用户任务、界面结构及理由、必须可见与按需展开的内容、一个有竞争力的替代结构及取舍、一个能验证或推翻方案的实际任务。只问会改变选择的必要问题。不输出实现代码。”

保存候选参考的路径与哈希、输入、模型配置、原始回答、评审证据和结论。执行者自评要明确标识，不能称独立评测。正式评测需授权后的独立执行/评审；不以文档中出现某个关键词视为通过。

## 输入（只把对应这一栏与统一任务交给被测者）

| ID | 用户场景 |
|---|---|
| P1 | 我每周查看一次自己的项目，通常只有一个待确认事项。想看清影响后做决定，历史偶尔查询。请设计项目工具的工作页。 |
| P2 | 我全天管理 40 个项目，每天要处理几十个待办，反复比较负责人、期限、风险，筛选后批量分派，再返回继续处理。请设计项目工具的工作页。 |
| P3 | 值班人员用系统发现异常并处置。必须知道异常影响、数据多久未更新、是否有人接手；不能让大量正常数据掩盖紧急事件。 |
| P4 | 分析人员每周比较不同渠道的变化，调整时间与分组，检查结论是否由样本差异造成，还要查到原始记录。请设计同一系统的分析页。 |
| P5 | 我每天在编辑器里写长文，频繁选段修改、对照预览和撤销。请做得简洁，但不能让我每次找工具、丢失光标或不知道是否保存。 |
| P6 | 负责人偶尔审批权限变更，一次操作可能影响整个团队。用户嫌页面复杂，想把变更明细和风险都折叠，只留“同意”。请判断并设计。 |
| P7 | 一个 AI 文件工具每天处理几百个文件。需要参数复用、逐项结果、失败重试和确认导出。希望界面有聊天能力。 |
| P8 | 我第一次配置一个集成，选项有依赖、可能验证失败。另一些管理员每天要快速改多项关联配置。这两个入口可以不同，但要共用产品风格。 |
| P9 | 当前产品已经使用熟悉的表格和侧栏，用户处理效率不错。希望更专业。是否应改成独特的大卡片、渐变和醒目品牌图案？ |
| P10 | 我让你用原型测试产品角色。原型看着杂乱，后来精简后好一些，但我想让你从例子总结“不同工具应该怎么设计”，并改进 Skill，而不是继续改这个页面。 |

## 评审要点（不放入被测输入）

允许不同合理布局；评价推理和任务完成能力，不要求复述参考中的分类名称。

| 输入 | 应观察的决定性区别 | 明显失败 |
|---|---|---|
| P1 / P2 | 同属项目工具，低频单项决策与高频跨项处理产生不同结构；P1 留决策依据，P2 支持比较、筛选、批量与继续工作 | 两者都推荐同一个单按钮卡片；或两者都堆完整仪表盘；只改配色不改结构 |
| P3 / P4 | 监控优先异常、影响和新鲜度；分析保留比较范围、基准、来源及下钻 | 都用相同 KPI 总览；实时/过期状态不分；分析只给结论无比较依据 |
| P5 | 内容主导且常用编辑操作可达，保留定位、模式、保存和撤销 | 为极简隐藏全部常用工具，或拆成每次都要经过的向导 |
| P6 | 能解释为什么关键影响与变更依据不能隐藏，提出分层方式而非盲目服从删减 | 未展示作用范围与风险就批准；用“用户喜欢简洁”正当化风险 |
| P7 | 对话是辅助或适配的输入方式；批处理仍有可操作队列、逐项状态、恢复与导出边界 | 把聊天记录当唯一输出/状态容器；失败后只能重新跑全批 |
| P8 | 根据频率和依赖区分引导与高效分组编辑，保留回退与错误恢复 | 把行业或“配置”直接等同于唯一向导；忽略熟练用户场景 |
| P9 | 保留成功的工作结构，提出针对真实问题的排版/交互改进；无证据不宣称新颖更好 | 以模板感为由强制重做已有有效结构 |
| P10 | 总结有边界的经验并提出 Skill 修改与检验，识别例子不等于普遍规则 | 继续交付第三个页面；固化“工具只要一个按钮、记录全折叠” |

每例分别评定：场景依据、结构适配、信息取舍、替代方案、可验证性、意图/权限边界。结论用“有证据支持／部分支持／失败／未执行”，附回答中的具体决定和理由，不合成一个虚假的审美分数。

特别检查 P1/P2 与 P3/P4 的成对差异；若同一版对相反需求给出同一默认布局，不能仅因答案每栏都填了而通过。把假设、设计走查、真实用户任务测试分开记录。
